# 项目 Skill 路由

当前没有已验证的项目 Skill，也没有从其他项目迁移流程。教学入口是 [teaching.md](../instructions/teaching.md)、[adaptive-tutoring.md](../instructions/adaptive-tutoring.md) 和 [material-design.md](../instructions/material-design.md)，任务维护入口是 [task-policy.md](../docs/task-policy.md)。任务元数据 `skills` 保持空列表，`instructions` 引用实际文件。

重复教学方法先在任务包内记录“候选流程”、适用条件及效果。至少在三次实际使用中有证据后，再评估是否值得建立独立 Skill；三次只是治理阈值，不代表教学效果已得到科学验证。

只在能明确触发条件、输入输出、步骤、完成判据、失败处理及证据位置时创建 `<流程名>/SKILL.md`。成立时更新此路由与任务引用，不复制已有 instruction。单次成功、临时教材使用或个人猜测不提升为 Skill。
