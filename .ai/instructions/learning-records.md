# 日期、学过的内容与进度

来源：2026-09-14 用户要求 AI 自动辨别日期、整理历史学过的词句、自行安排整理触发时机，并用于观察学习进度。

## 每次回答前核对太平洋时间（2026-10-26）

用户明确要求“加上一个回答前要看当前太平洋时间的约定”。每次收到用户消息后，先运行 `python3 tools/study_clock.py`，再给出实质回应；适用于教学、规划、纠错及规范讨论。连续工具调用属于同一回合，不必每个调用重复读取；如果长时间执行、跨日或即将作最终交付，再刷新一次。无法读取时明确未知，不复用旧时间冒充当前。

太平洋时间使用 `America/Los_Angeles`，自动区分PDT和PST，不固定写成UTC-8。此要求增加回答前检查，没有把学习记录时区改成太平洋：日页、课次日期和考试倒计时继续按`Asia/Singapore`，同时显示两地时间时标明时区。考试倒计时可运行 `python3 tools/study_clock.py --exam-date 2026-12-06`；考期改变后使用经确认的新日期。

## 开始或接续时

1. 先确认本轮当前日期和用户时区，不能沿用旧页面日期。默认时区来自学习索引，目前为 Asia/Singapore；用户明确变更时更新。实际时钟与会话日期不一致时先核实，不凭旧文档或文件修改时间猜日期。
2. 运行 `python3 tools/study_progress.py sync`。程序按本机当前时刻换算用户时区，使用当天页面；不存在则独占新建，不覆盖旧页。日期不需要用户手动触发。随后老师填入本次实际开场或接续，不把空模板算作学习。
3. 读取当天页、最近旧页及学习进度。旧页待回复的内容可以接到今天讲，但原答留在原处，并链接来源；不改写旧日期。更新任务包的当前入口与接续说明。
4. 日期页创建、复习编排、材料写入、就绪核验分别处理。材料写入后运行 `python3 tools/study_progress.py ready --teacher-turn <本轮老师回合> --reply-turn <作答回合>`；通过前不宣称已备好，不引导用户去不存在的小节。就绪核验为只读，检查当天真实四项基础材料及独立分块辅助行、随后作答位与当前课次的复习编排。

## 每轮有实质学习内容之后

- 先把真实对话保存进当天 Markdown，按双入口规则去重。
- 教师判断真正教过的目标，在 `日常练习/学习索引.json` 维护稳定词条 ID、日语、罗马音、中文意思、类型和证据。新项目必须有来源，不把提到的所有词、参考词库或预备材料全部算成学过。
- 证据标明日期、文件、回合、原文片段、提示条件；同一词的重复接触使用同一个项目 ID，不重复计作新词。新增事件使用唯一 ID。同一文件重复读取不会产生新的学习事件。
- 历史跨日回复优先采用明确的回合日期或当时记录；日期不确定时先查证，不能以今天的整理日期假充学习日期。尚不能确认的内容保留在任务说明中，不硬填索引。
- `exposure` 表示教学接触；`attempt` 表示实际尝试；`supported-correct` 表示有提示下写对；`review-verified` 仅在隔日、无提示的实际正确回应经教师判读后登记，并写明判读依据。程序不负责判断日语是否正确。
- 完成索引更新后再次运行 `sync`，刷新派生的 `日常练习/学习进度.md`。编辑索引前备份；进度页可由证据重建，不作为原始作答来源。
- 同一轮在统一 `能力变化.json` 的当前课次增量保存已观察到的理解、提示与输出、输入困难等事实；证据不足的维度保持未知，后续表现可修订暂时判断。当前课次可以标记为进行中，不要求先完成一堂课才有观察记录。恢复点与复习未完成项也随实际消息更新。

## 可随时中断的增量学习

学习是连续的小步互动，不是必须完整执行的章节流程。词句接触、实际尝试、纠错与复习回应发生后即在本轮安全落盘；不等结束时批量归档，不依赖用户说“总结”“结束”才能保存。开场编排复习仍执行，材料量与停止时机随用户调整。

用户临时有事可直接停止，不要求补做测验、总结或结课仪式。明确结束时可更新状态，但只是可选核对机会，不是数据提交门槛。中断后若课次仍标为进行中，下次从最后安全记录恢复，不把它当未交作业；无结束证据时不编造结束时间。用户正在编辑同页时，按编辑交接规则先将待同步内容安全保存在本地恢复区，不能为了逐轮保存抢写。

## 暂停或结束时

可核对本轮对话及事件是否已收录，刷新进度和任务接续；不要求用户等待总结，也不把这一步作为此前记录的提交条件。记录仍未验证的部分，不把未回答写成不会。必要时运行 `check` 验证索引来源。

## 复习由老师安排

### 开课第一轮的复习编排（2026-10-08）

每堂课开始、接入新学习任务时，在第一轮正式教学之前由教师完成以下准备，用户不必选择或提醒：

1. 核实日期并运行 `sync`，读统一学习索引、最近能力记录和相关原始作答，先判断哪些旧内容值得重遇。脚本候选只是提示，不替代教师阅读真实表现。
2. 参考约1、3、7天的可调整间隔，结合距上次接触的时间、隔日表现、是否依赖提示、尚未解决的疑问及当前状态选少量内容。未验证的记忆保留未知；不能由固定遗忘曲线算出用户的精确遗忘概率，也不能把一次照抄正确当作长期记住。
3. 在准备的新词句、短对话或例句中安排旧内容出现的位置。先编排这一课的起步片段，不预先锁死整堂课的学习量；不是另开一轮旧课或测验。太难拆小，熟悉时减少重复，用户换方向时即时调整。
4. 在 `学习索引.json` 的当前 `sessions` 条目内保存 `reviewPlan`：编排发生的阶段、所选稳定项目ID、选择依据、拟穿插位置，以及已呈现和待观察的区别。真正重遇后才追加对应项目事件与 `revisitedItemIds`；预选不算已复习。课中改变方案时在同一课次更新并说明原因，不另建每日复习数据文件。

开场漏做时，坦诚记录为课中补排，不追填成“开场已安排”。未完成的计划可以下次重新判断，不形成补课债。

### 复习闭环与未完成项（2026-10-08 补充）

编排不是记录的终点。课中在同一课次 `reviewPlan.targets` 更新每项实际呈现、回应证据、提示条件、结果及下一步；区分未呈现、呈现待回应、带提示回应、仍需帮助、主动暂缓和取消。实际事件仍统一保存在对应 `items.events`，计划引用回合，不另建统计源。

每轮按实际进展核对：没有来得及穿插、未回应或还需帮助的内容，及时保留理由和具体接续建议，不留到收尾才记；取消的题注明取消，不能写成不会。需后续处理的纠错也可在当前课次 `followUps` 中引用证据保存。下次开场读取尚未处理的目标，决定融入新材料、继续帮助、暂缓或取消并说明依据；跨课处理要引用原课次，不能随着日期改变自动消失，也不强迫当日全做完。呈现过不等于记住，带提示完成不等于隔日无提示验证。

初始采用约 1、3、7 天的重遇间隔，依据反馈调整，不称为唯一最佳间隔。到下一次实际互动时，从候选中挑 1–2 项融入剧情或生活场景；用户想学新句、时间少或不愿复习时可跳过，不累计补课债。脚本显示候选，老师决定是否与怎样使用。

2026-10-08 用户明确复习形式：优先把候选旧词句穿插进正在教的新知识、例句或对话，让它们自然反复出现，不把候选名单直接变成一轮旧词考试。单独回顾仅在用户要求或需要解决具体疑问时使用。自然重遇可以带释义；不能因为呈现过就登记隔日无提示验证。

这是接续时自动执行的工作流程。聊天外提醒只有在实际创建成功后才算启用，是否启用及其运行边界另记任务包；不能把写入督学规则说成已经创建定时推送。用户不必提醒换日期或统计，没有实际运行时不声称持续更新。

## 进度口径

- “学过”=已有教学接触，和“掌握”分开。
- 分别显示去重后的词条数、表达/语法数、有输出练习记录数及隔日无提示复习验证数；这些是有包含关系的计数，不相加成总成绩。
- 无证据不计为复习通过，不把看提示输入正确算成独立掌握。当前不使用永久“已掌握”标签。
- 日期页数量只表示页面数，不等于连续学习天数或有效时长。没有计时就不生成学习时长。
- 不用学过数量除以参考词库总数，冒充 N3 完成百分比。应试覆盖仍需词汇、语法、阅读和真实听力的分别证据。
- 日常 Markdown 是原话来源，学习索引是教师维护的证据索引，学习进度是派生视图；正式任务状态仍只由任务包的 TASK-META.json 决定。

## 三层记录与每堂课关联（2026-09-16）

每日 Markdown 是对话、作答和反馈的课堂原始记录；学习索引.json 是唯一学过内容汇总，items 去重存词汇表达语法，sessions 按课次记录本课新学与重遇项目 ID、内容摘要及原记录路径；能力变化.json 是唯一课堂评价与变化记录，按同一课次 ID 保存观察、提示条件、未测项和调整依据。同一天多课用不同课次 ID。两份汇总跨日跨任务增量维护，不为每堂课另造统计文件；每日记录不承担第二套统计。课中确保两份数据关联当前课次，评价不能用新增词数代替。历史课次未整理时保持待补，不编造。

## 课时与等待的记录边界（2026-10-27）

执行[教学规则](teaching.md)“突击课时、等待耗时与自然收束”。课次`pacingPlan`保存教师暂定收束观察时间、位置、依据和调整；统一能力记录保存已知耗时与证据。时钟经过时间与净参与时间分开，消息间隔不是专注计时；未知的`activeLearningMinutes`保持null。用户同意继续不等于确认听过音频或完成上一题。

2026-10-28格式补充：按[教学规则](teaching.md)“独立分块辅助”保留正常原文并多加一行；ready检查辅助行及其与原文的同文关系。旧作答和历史原文不批量改写，当前教师材料只补行；分块支撑作为实际阅读条件记入统一课次，不能把有分块的表现冒称无辅助识读。
