# 学习任务模板（不是活跃任务）

AI 将本目录复制到 tasks 下的新目录，替换元数据 ID、标题、范围、时间及产物路径；元数据路径相对于项目根。填写以下文件中的实际内容，未填写前保持 draft。不要把占位文字复制后标为 ready。

阅读顺序：TASK-META → 学习目标与计划 → 接续与变更 → 教法探索 → 作答与反馈/验收与证据。状态以 JSON 为准，不维护多个状态表。

类型适配：baseline 写起点观察与未测边界；learning-unit 写一个具体理解目标及延后/迁移标准；exam-practice 写材料版本、题号、限时和音频条件、分项表现；project-setup 写文件契约、实际检查和恢复依据。

本核心模板将参考结构中的需求/方案/契约合并到目标与计划，进度/变更/日志合并到接续文件，证据/验收合并到验收文件；教法探索保存教学方法的条件与判断。不为形式复制多份空文档。
