## 重点意味着什么

`official-sample` 仅表示是2012/2018官方N3词汇练习册中指定题目的目标词或表达。此次核对两册的第1、2、4、5大题，共48目标；未清点第3大题或语法、阅读、听力。出现一次不能换算成高频或必考。

`logic`、`boundary`、`workflow`、`software`、`story` 等标签是按理解价值、软件式样书和兴趣选择的教学优先级，不是频率统计。三语释义为教师整理，非官方译文。原作兴趣词不等于摘录自作品。

先选一个可理解场景，再从库里选少量相关词并核对词义与搭配，不按库的行数布置背词配额。用户主动想查词或系统学习时正常提供，不以自然习得为由禁止显性学习。

本库不保存掌握状态。回应、提示、重遇和记忆证据仍在学习任务包；收录、翻译、讲过都不等于学会。

## 查询和维护

项目根目录运行，无需网络或额外 Python 包：

```bash
python3 tools/vocabulary.py search 确认
python3 tools/vocabulary.py search --level N3 --priority --limit 10
python3 tools/vocabulary.py search --tag official-sample --limit 5
python3 tools/vocabulary.py search --tag software --limit 5
python3 tools/vocabulary.py check
```

修改人工整理内容时，先按备份政策修改任务包 `assets/curated-input.json`，记录来源和变更，再运行 `python3 tools/vocabulary.py build`。不要直接改生成视图；构建工具为有差异的旧输出保留备份。上游版本更新应保存新快照并比较，不自动联网覆盖。

当前162条有中文教学释义，另2,820条尚未补中文；原始N3表有13行缺英文。这些已标记，没有猜测填满。全库未做独立词典逐词审校；旧字形、分级和过简释义需在实际教学前核对。
