# 资料建设检查

本包没有教学练习。实际检查命令在项目根运行：

```bash
python3 tools/vocabulary.py build
python3 tools/vocabulary.py check
python3 tools/vocabulary.py search 确认 --limit 2
python3 tools/vocabulary.py search --tag official-sample --limit 2
python3 tools/vocabulary.py search --tag software --limit 2
python3 tools/check_project.py
```

检查来源哈希、生成一致性、全部原始行覆盖、同音异词、重点三语、官方题号、数值边界和查询。软件检查不代替全量语言审校。
