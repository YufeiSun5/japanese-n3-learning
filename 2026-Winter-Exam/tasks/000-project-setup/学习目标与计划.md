# 需求、方案与范围

用户要求初始化 AI 治理的 N3 学习工程，以参考的项目稳定规则与任务包模型为基础，结合自然习得和编程思维。经首轮方案后，用户明确要求“你设计这个 ai 治理辅导我的工程”；随后强调传统方式失效，要求像研究员一样持续探索、更换教法。

扫描事实：工作区仅有空的 2026-Winter-Exam 目录，无旧文件、规则、任务或代码。沿用目录，不推断考期。

实施：根级入口与长期约定 → .ai 稳定教学和维护规则 → 一个教师角色 → 核心任务模板与起点观察包 → 官方资料登记 → 结构检查和恢复清单。

交付契约：用户通过一句自然语言开始；AI 能仅凭文件接续；任务事实不混入长期记忆；没有虚构学习成绩；教法可依据观察调整。无需安装依赖、建立网站、购买教材或开启自动化。初始化不自动开始实际课程。

首次仅创建新文件，原始空目录保留。回退按初始化清单和任务政策逐项处理，不删除后续学习记录。
