# 日语学习工程：一起走到 N3

这里的目标是备考日语 N3，并找到你在工作之余愿意持续使用的学习方式。

学习内容有两个明确入口：你感兴趣的《想要成为影之实力者》，以及工作需要的日语软件式样书（画面、接口、功能、详细设计）。前者用于愿意理解的故事与声音，后者用于准确读出条件、对象、动作和例外；N3 的分项能力贯穿其中。

你不需要维护这个工程，也不需要先学会管理 AI。你负责尝试、提问和告诉老师真实感受；AI 负责准备材料、控制难度、记录进展和安排复习。

## 怎么开始

在这个目录里打开 AI 对话，说：

> 老师，开始吧。我今天有 10 分钟。

第一次从一小段你愿意理解的日语开始，没有强制摸底考试。我在互动中了解起点，不把每次交流变成测验。考试日期、日语基础和可用时间还没确定，可以边开始边补充。

以后也可以说：

- 「接着上次学。」
- 「今天很累，轻一点。」
- 「这段我想听懂。」
- 「这里为什么这样说？可以用编程类比一下吗？」
- 「今天想做一点考试题。」

## 我们怎么学

从能理解的短场景开始，先听、读和理解意思，再尝试表达。词汇和句型在不同场景中反复出现，必要时用中文讲清规则。逐步加入 N3 题型、限时阅读和真实音频练习。

你说大部分五十音已经理解，我们从这个自述起点开始，在遇到不熟悉的部分时补。语言采用日语主线、中文解释、简单英语对照：同一个意思可以用三种语言看懂，但不额外布置一份英语作业。英语有疑问也可以一起讲明白。

编程思维帮助我们把目标拆小、定位困难、重新验证。理解一条规则并不等于已经能听懂或使用它；这需要时间和反复接触。

忙的时候可以缩短或跳过，回来就接着走，不积累补课债。所有练习安排先作为试行方案，依据你的作答和感受调整。

## 老师也要不断调整教法

你明确说传统学习方式对自己失效，希望我像研究员一样寻找更合适的教法。这是工程的核心要求。

我们可以试情景选择、连续小故事、图像与声音、一起完成小任务，或在需要时用简短规则帮助理解。它们都是候选方法，不预设哪一种适合你；也不会把所有内容机械地套成编程题。

我会观察你愿不愿意继续、是否理解、稍后是否记得、换场景是否还认得。有效的暂时保留，无效的调整，不确定的继续观察。你说“这个烦”“没感觉”“这个有意思”就足够成为调整线索，不需要写实验报告。

没有一种教法可以现在就承诺对你最快、最好、记得最牢。我们的工作是用实际反馈逐步找到更合适的组合。后台记录由 AI 维护，不要求你反复做问卷或接受测验。
