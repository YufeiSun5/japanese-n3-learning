# 日常练习

按日期保存边聊边写的日语练习，老师提示与用户原文都留在当天文件里。

2026-09-08 用户明确要求：保留之前的内容，便于回看自己做过什么。此后老师只在末尾追加短提示或反馈，不替换、缩写或删除之前的提示及用户作答；纠正也另行追加。用户主动要求整理时，先保留完整原稿。

修改前重新读取文件；编辑器若有未保存内容，先保全该内容，避免覆盖用户正在写的练习。不替用户填写答案。

对话排版：按发生顺序使用「**我：**」「**老师：**」接续，每次发言在底部追加，形成可以一直向下滚动的对话。不设固定的“我的练习区”和“老师提示区”。老师的新提示默认只写简短一句；连续的老师说明可放在同一发言中，不补造用户回复。来源：2026-09-08 用户当场澄清。

排版补充（2026-09-08）：用户要求 Markdown 清楚美观。使用“### 01 · 我 / ### 02 · 老师”这样的顺序编号标题与水平分隔线；短提示用引用块，长的历史说明保留在可展开区域。底部为当前待续发言，用户原文不变。整理仅改变呈现，不丢失历史。

沟通方式更新（2026-09-14，替代 09.13 的仅文件交流限制）：用户和老师可在项目文件或会话窗口回复，实质对话完整保存到当天 Markdown。老师先读最新内容，再按实际顺序追加并去重；用户无需在两边重复提交。每次处理消息时同步，不是后台实时监听。保留原话、教学、反馈和剧情；工具日志与重复进度通知不放入练习页。

跑团由主持人推进场景和合理后果，用户自由决定行动，可用中文，不把开放回应当作等待标准答案的试题。不替用户决定行动或填写回复。

## 自动日期与学习汇总（2026-09-14）

AI 在接续时自动确认当天日期，使用当天页面；每轮与暂停时整理已学目标并刷新 [学习进度](学习进度.md)。用户不必手动要求换页或汇总。原始对话保持不变，跨日未完成内容可在新页接续。

[学习索引](学习索引.json)保存去重目标与来源；“学过”仅表示接触过，练习、隔日无提示复习验证分别统计。具体执行见 [日期与进度规则](../.ai/instructions/learning-records.md)。汇总命令：`python3 tools/study_progress.py sync`；来源检查：`python3 tools/study_progress.py check`。
