# 学习观察与节奏调整

这是统一能力变化记录的阅读说明；所有会话的数据集中在[能力变化](能力变化.json)，跨任务按日期追加，不分散到每日文件或任务包。词句数据集中在[学习索引](学习索引.json)。原话仍在每日记录，任务状态仍以任务元数据为准。

## 每次实际学习结束后记录

| 维度 | 记录方式 | 调整用途 |
| --- | --- | --- |
| 理解 | 记录能否解释意思、区分变化、在新情境回应及具体证据 | 选择解释深度与下一步跨度 |
| 提示依赖 | 无提示／轻提示／范句或译文可见／分步带做；未知留空 | 不能把照抄与独立使用比较 |
| 输出 | 实际目标数、首答结果（有记录才计）、纠正后结果分别统计 | 判断错误在哪里，不以重复次数加分 |
| 延后记忆与迁移 | 隔日、换情境的实际回应，记录提示条件 | 安排重遇，不能用同日重复替代 |
| 输入操作 | 假名选择、长音、转换或保存困难单独记 | 不把打字困难当语言能力下降 |
| 速度 | 有有效学习计时且任务可比时，记完成情况及提示量；否则未知 | 不用会话跨度或打字速度冒充学习速度 |
| 负荷与意愿 | 用户自述、主动提问、要求休息等具体事实 | 不猜心理，不自动打热情分 |
| 考试覆盖 | 词汇语法、阅读、真实听力的证据与缺项 | 决定后续材料 |

比较只在任务难度和提示条件相近时进行；否则给定性观察并说明不能比较。没有数据写未知，不填零。开始阶段不合成总能力值；将来若使用数值尺度，须有明确锚点与证据，不能包装成标准化测评。教师自主记录，不要求用户每课填写问卷。记录反馈和具体后续调整，随下一次结果修正。

## 统一存储

能力观察只更新 能力变化.json；词汇、表达和语法只更新 学习索引.json。此页解释字段口径，不重复保存每日统计。日常原话按日期保存作为证据，汇总只引用来源。
